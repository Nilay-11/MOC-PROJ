MOC Mini Project / Models of Computation

Catching phishing URLs with finite automata.

A URL is just a string. We turn each suspicious pattern, like login, @ or an IP address, into a small DFA. The DFAs read the URL one character at a time, and every pattern they find adds to a risk score.

How it works

Four steps from pattern to verdict.

  1. 1

    Write the pattern

    Each warning sign is a regular expression.

    .*login.*
  2. 2

    Regex → NFA

    The expression is converted into an NFA.

    18 states
  3. 3

    NFA → minimal DFA

    The NFA becomes a DFA, then the smallest possible DFA.

    6 states
  4. 4

    Read the URL

    If the DFA ends in an accepting state, the pattern was found and points are added.

    score ≥ 4 → High Risk
Try it

Paste a URL.

13 DFAs read it. Each pattern found adds points: 0–1 is Low Risk, 2–3 Suspicious, 4 or more High Risk.
